# 1D Pacman

## Minimum Requirements

**1-Dimension Pacman**

   - Implement a single-row game area where Pacman moves left or right, consuming pellets.
   - At least one type of enemy moves along the row and interacts with Pacman (e.g., causes "game over" upon collision).
   - Include a score counter displayed on the screen.
   - Add a restart functionality when the game ends.
   - Relevant source:
     - <https://arlagames.itch.io/paku-paku-c64>

## Extra Recommended Features  

Consider adding the following enhancements to improve your project:

- **Title Screen**
  - Create a title screen that displays the game's name and provides instructions or a prompt to start the game.

- **Detailed Animations**
  - Animate game elements or objects interactions.
  - Use smooth transitions or blinking effects to highlight significant game events.

- **On-Screen Display**
  - Display additional information like the current level and remaining lives.

- **Dynamic Difficulty or Levels**
  - Introduce multiple levels of increasing difficulty.
