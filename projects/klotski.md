# Klotski

## Minimum Requirements

**Klotski** (also known as: Huarong Dao or Red Donkey)

  - Implement a 4x5 grid containing movable tiles.
  - Include at least one puzzle to solve, such as moving a "main tile" to a specific exit position.
  - Adhere to movement constraints based on tile size and grid rules.
  - Provide a reset functionality to restart the puzzle.
  - Relevant source:
    - <https://www.cs.brandeis.edu/~storer/JimPuzzles/ZPAGES/zzzRedDonkey.html>

## Extra Recommended Features  

Consider adding the following enhancements to improve your project:

- **Title Screen**
  - Create a title screen that displays the game's name and provides instructions or a prompt to start the game.

- **Detailed Animations**
  - Animate game elements or objects interactions.
  - Use smooth transitions or blinking effects to highlight significant game events.

- **Step Counter and Level Number**
  - Add an on-screen step counter and display the level number.
