# Sokoban

## Minimum Requirements

**Sokoban**

  - Implement a grid-based level with at least 5 (five) playable levels.
  - Allow the player to push boxes to target positions while adhering to Sokoban rules.
  - Include a win condition that triggers when all boxes are correctly placed.
  - Provide a reset functionality to restart the current level.
  - Relevant source:
    - <https://www.mathsisfun.com/games/sokoban.html>

## Stretch Goals

Consider adding the following enhancements to improve your project:

- **Title Screen**
  - Create a title screen that displays the game's name and provides instructions or a prompt to start the game.

- **Detailed Animations**
  - Animate game elements or objects interactions.
  - Use smooth transitions or blinking effects to highlight significant game events.

- **Step Counter and Level Display**
  - Add an on-screen step counter, and the number of the current level.
